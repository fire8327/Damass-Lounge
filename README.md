# 🍸 DAMASS — Lounge & Bar (Канаш)

Эдиториал-лендинг для вечернего кафе и лаунж-бара **«Дамасс»** в городе Канаш (Чебоксарская ул., 29).

---

## 📌 Особенности концепта

- **Эстетика без «ИИ-слопа»:** Строгий темный нуар-дизайн (`#07080a`), глубокие тона, акценты античного золота (`#c59b27`), утонченная типографика (`Playfair Display` + `Inter`). Без шаблонных 3-колоночных иконок и без стоковых клише.
- **Только проверенные факты:**
  - Реальный адрес: *Чувашская Республика, г. Канаш, Чебоксарская улица, 29*
  - Режим работы: *Пн–Чт: 16:00–00:00; Пт–Сб: 16:00–01:00; Вс: 16:00–00:00*
  - Контактный телефон: *+7 (937) 388-80-02*
  - Реальный средний чек: *500–800 ₽*
  - Формат: *Европейская и восточная кухня, блюда на мангале, авторские кальяны, караоке и VIP-залы*
  - Соцсети: *Telegram @cafe_damass, ВКонтакте vk.ru/damasskanash*
- **Реальные фотографии:** Фотографии залов, барной зоны, блюд и кальянов получены напрямую из профиля заведения на Яндекс Картах.
- **Интерактивная карта:** Встроенный виджет Яндекс Карт с точной меткой на здании (координаты `55.51433, 47.472756`).
- **Интерактивность:** Фильтрация меню по табам, мобильное меню и продуманная форма онлайн-бронирования стола и VIP-комнат.
