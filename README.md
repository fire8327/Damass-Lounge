# 🍸 DAMASS — Lounge & Bar (Канаш)

Эдиториал-лендинг для вечернего кафе и лаунж-бара **«Дамасс»** в городе Канаш (Чебоксарская ул., 29).

---

## 📌 Особенности концепта и редизайна

- **Bespoke Editorial Noir:** Премиальная эстетика вечерней гастрономии и лаунжа. Глубокие обсидиановые тона (`#060709`, `#0c0e12`), акценты золота (`#d4af37`), кинематографичный свет, пленочная микротекстура (`grain overlay`) и высокая типографика (`Playfair Display`, `Cormorant Garamond`, `Plus Jakarta Sans`).
- **Оригинальный блок 1 — «Куратор вечернего сценария» (Damass Evening Curator):** Интерактивный подбор атмосферы отдыха («Дымный лаунж & Чайная церемония», «Закрытый VIP & Караоке», «Кухня на мангале & Гриль») с мгновенным переносом параметров в бронирование стола.
- **Оригинальный блок 2 — «Калькулятор депозита и чека вечера»:** Интерактивный расчет чека компании в зависимости от числа гостей, зоны и блюд с прозрачным средним чеком на человека.
- **Динамический VIP Guest Pass:** Цифровой билет гостя с уникальным идентификатором брони, обновляющийся в реальном времени при заполнении формы, а также кастомное модальное подтверждение.
- **Live-статус Канаша:** Часы реального времени Канаша (MSK UTC+3) с автоматическим расчетом статуса работы заведения (`Открыто сейчас` / `Ждем гостей с 16:00`).
- **Только проверенные факты:**
  - Реальный адрес: *Чувашская Республика, г. Канаш, Чебоксарская улица, 29*
  - Режим работы: *Пн–Чт: 16:00–00:00; Пт–Сб: 16:00–01:00; Вс: 16:00–00:00*
  - Контактный телефон: *+7 (937) 388-80-02*
  - Реальный средний чек: *500–800 ₽*
  - Соцсети: *Telegram @cafe_damass, ВКонтакте vk.ru/damasskanash*
- **Реальные фотографии:** Фотографии залов, барной зоны, блюд и кальянов получены напрямую из профиля заведения на Яндекс Картах.
- **Чистая интерактивная карта:** Встроенный виджет Яндекс Карт с точной меткой на здании (координаты `55.51433, 47.472756`) без лишних наложений.

## 📁 Структура проекта

```text
Damass-Lounge/
├── index.html        # Главная страница эдиториал-лендинга
├── css/
│   └── style.css     # Дизайн-система Editorial Noir, капсульные табы, модальные окна
├── js/
│   └── main.js       # Логика куратора сценариев, калькулятора, живого статуса и формы
├── images/           # Аутентичные фотографии заведения
├── server.js         # Легковесный локальный статический сервер
└── README.md         # Документация проекта
```

---

## 🚀 Запуск проекта

1. **Прямое открытие:** Откройте `index.html` в любом современном браузере.
2. **Локальный сервер:**
   ```bash
   node server.js 3001
   ```
   и перейдите по адресу `http://localhost:3001`.
